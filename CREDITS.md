# Créditos

Este proyecto no habría existido sin el ecosistema abierto que está creciendo alrededor de [Claude Code](https://docs.anthropic.com/en/docs/claude-code). La idea de empaquetar flujos de trabajo completos como "skills" — carpetas con un `SKILL.md` que Claude lee y ejecuta — viene de esa comunidad. Muchas de las decisiones de arquitectura (orquestador principal + sub-skills + agentes paralelos + scripts en Python + plantillas reutilizables) se inspiran directamente en los patrones que otros desarrolladores han compartido públicamente en GitHub y foros.

Gracias al equipo de Anthropic por construir Claude Code y abrir el formato de skills, y a todos los que publican sus propias suites de skills en abierto. Este repo intenta devolver algo al ecosistema: una adaptación en castellano, orientada a mercado hispanohablante y pensada para gente que vende servicios de marketing con IA.

Si encuentras algo útil aquí, considera publicar también tus propias skills. El ecosistema crece más rápido cuando compartimos.
